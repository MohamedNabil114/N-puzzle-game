# 🧩 N-Puzzle Game (AI Project)

An interactive and intelligent version of the classic **8-puzzle** game, developed in **Python** using **Pygame**. This project was created as part of an **Artificial Intelligence course**, showcasing the application of informed search algorithms.

## 🎯 Overview

The game simulates the well-known 3x3 sliding puzzle (8-puzzle), offering two modes of play:

- 🎮 **Manual Mode**: Solve the puzzle by clicking and moving the tiles yourself.
- 🤖 **Auto-Solve Mode (A\*)**: Let the AI solve the puzzle using the A* search algorithm with the Manhattan distance heuristic.

Watch a demo video here:  
📺 [N-Puzzle Game Demonstration on YouTube](https://youtu.be/HEoLoa1pUZU)

---

## 🧠 AI & Algorithm

- **Search Algorithm**: A* (A-star)
- **Heuristic Function**: Manhattan Distance (number of moves required to reach the goal state)

The A* algorithm ensures the most efficient solution path by combining:
- `g(n)`: cost from start to current state  
- `h(n)`: estimated cost from current state to goal
